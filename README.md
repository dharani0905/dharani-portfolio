# Dharani Vanukuri — Portfolio

A responsive, interactive professional portfolio for Dharani Vanukuri.

## Features
- Modern responsive layout with light/dark toggle
- Animated hero, subtle scroll-reveal sections
- Expandable project highlights
- Professional experience timeline
- Accessible mobile navigation, reduced-motion support
- No build tooling required

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a public GitHub repository called `dharani-portfolio` under **dharani0905**.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` at the repository root.
3. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, `main`, `/ (root)`, then Save.
4. After publication, the expected site address is `https://dharani0905.github.io/dharani-portfolio/`.

## Content notes
